# Contributing

Thanks for contributing to Gemi Dompet. Before opening a pull request, create a focused branch from `main`, install dependencies with `npm ci`, and run:

```bash
npm test
npm run build
```

Keep changes scoped, use the repository's TypeScript and Tailwind conventions, and add tests for financial calculations, validation, or authorization changes. Do not include credentials, database dumps, generated build output, or unrelated formatting changes.

Open an issue before substantial new features or changes to data models. Pull requests should explain the user-facing behavior, note migrations or environment changes, link the issue where applicable, and include screenshots for UI changes.
